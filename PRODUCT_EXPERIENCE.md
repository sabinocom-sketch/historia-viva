# História Viva product experience

## Positioning

História Viva is an interactive historical learning experience.

It should not feel like an encyclopedia, a quiz bank, or a static course. The strongest product shape is a guided journey where the user investigates historical worlds through short lessons, evidence, choices, debate, XP, and campaign progress.

## Product Promise

Help the user feel like an investigator of History: curious, capable, and pulled forward by discovery.

The experience should answer one question every time the user enters:

> What historical thread am I continuing today?

## Core Loop

```txt
Discovery
↓
Short lesson
↓
Interaction
↓
Reflection or debate
↓
XP and progress
↓
Next discovery
```

## User Fantasy

Primary fantasy:

```txt
I am an investigator of History.
```

Supporting fantasies:

- explorer
- chronicler
- strategist
- time traveller

The app should avoid making the user feel like they are merely reading school notes. They should feel they are reconstructing, comparing, deciding, and interpreting.

## Experience Modes

### Learn

```txt
Lesson → interaction → feedback → next lesson
```

### Explore

```txt
Theme → relation → comparison → new curiosity
```

### Interact

```txt
Challenge → response → feedback → XP → new challenge
```

## First Campaign

### Ascensão e Queda de Roma

Product goal:

Make the user feel they are investigating how Rome became powerful and why that power created new tensions.

Current flow:

```txt
Guerras Púnicas
↓
Quiz
↓
Fonte
↓
Debate
↓
Missão

+40 XP
```

## Long-Term Retention

Reasons to return tomorrow:

- continue a campaign
- keep a streak
- unlock a mission
- finish a historical arc
- discover a new era
- level up
- revisit a debate with better evidence

## Experience Evolution

Early experience:

- simple
- cinematic
- low-friction

Middle experience:

- more analytical
- more comparative
- more evidence-based

Late experience:

- campaigns
- decisions with consequences
- synthesis across eras
- deeper historical argumentation

## Product Rule

History Viva should not ask:

```txt
Which section do you want to open?
```

It should ask:

```txt
What part of the journey are you continuing?
```
